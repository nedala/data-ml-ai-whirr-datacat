# datacat brand assets

| File | Use |
|---|---|
| `datacat.svg` | **Primary mark (chosen): plain yellow line cat**, no background. App headers, launchpad, docs. |
| `datacat-tile.svg` | Alternate: the same cat on a charcoal rounded tile, for small sizes or white backgrounds where yellow alone is faint. |
| `datacat-wordmark.svg` | Mark + "datacat" wordmark (data in charcoal, cat in fiber teal). Login screens, docs hero. |
| `datacat-line.svg` | Monochrome line cat (`currentColor`) for inline use on coloured backgrounds. |
| `favicon.svg` | Simplified mark for 16–32 px (thicker strokes, no face). |

Colours: signal yellow `#FFCF00`, charcoal `#1C2127`, fiber teal `#0B6E79`.
Style: single-weight rounded strokes; keep clear space of ¼ tile width around the mark.
